Privacy Policy - SiUjian

Last Updated: December 19, 2024

Bahasa Indonesia

1. Pendahuluan

SiUjian adalah aplikasi browser ujian terkunci (secure exam browser) yang dirancang untuk membantu guru dan siswa dalam pelaksanaan ujian berbasis web. Aplikasi ini TIDAK mengelola soal, jawaban, atau nilai ujian.

2. Data yang TIDAK Kami Kumpulkan

SiUjian berkomitmen untuk menjaga privasi pengguna. Kami TIDAK mengumpulkan, menyimpan, atau mengirimkan data pribadi apapun, termasuk:

  • Nama atau identitas pengguna
  • Alamat email
  • Nomor telepon
  • Data lokasi
  • Jawaban ujian
  • Nilai atau hasil ujian
  • Foto, video, atau media lainnya
  • Riwayat browsing

3. Data yang Diproses Secara Lokal

Data berikut hanya tersimpan di perangkat Anda dan TIDAK dikirim ke server kami:

  • Status premium (apakah Anda sudah membeli upgrade)
  • Jumlah token yang dibuat hari ini (untuk batasan akun gratis)

Data ini dapat dihapus dengan menghapus data aplikasi melalui pengaturan perangkat.

4. Token Ujian

  • Token ujian adalah kode sementara yang menghubungkan URL ujian
  • Token memiliki masa berlaku (default: 2 jam)
  • Token tidak berisi informasi pribadi
  • Token disimpan di server untuk sementara dan dihapus setelah kadaluarsa

5. Koneksi Internet

Aplikasi memerlukan koneksi internet untuk:

  • Membuat token ujian (Mode Guru)
  • Memvalidasi token (Mode Siswa)
  • Memuat halaman ujian web (Google Form, Kahoot, dll)
  • Memproses pembelian melalui Google Play

6. Pembelian Dalam Aplikasi

Pembelian diproses sepenuhnya melalui sistem Google Play Billing. Kami TIDAK menyimpan informasi kartu kredit atau pembayaran Anda. Silakan lihat Kebijakan Privasi Google untuk informasi lebih lanjut.

7. Izin Aplikasi

INTERNET Diperlukan untuk mengakses halaman ujian berbasis web
Screen Pinning/LockTask Untuk mengunci layar selama ujian berlangsung

8. Keamanan

  • FLAG_SECURE aktif selama ujian untuk mencegah screenshot dan rekam layar
  • Data WebView (cache, cookies) dihapus otomatis setelah ujian selesai
  • Domain dibatasi hanya pada URL ujian yang valid

9. Privasi Anak-Anak

Aplikasi ini dirancang aman untuk digunakan oleh anak-anak (siswa) karena:

  • Tidak mengumpulkan data pribadi
  • Tidak menampilkan iklan
  • Tidak ada fitur sosial atau chat
  • Tidak ada konten buatan pengguna

10. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan signifikan akan diumumkan melalui pembaruan aplikasi.

English Version

1. Introduction

SiUjian is a secure exam browser application designed to help teachers and students conduct web-based examinations. This app does NOT manage exam questions, answers, or grades.

2. Data We DO NOT Collect

SiUjian is committed to protecting user privacy. We do NOT collect, store, or transmit any personal data, including:

  • User names or identities
  • Email addresses
  • Phone numbers
  • Location data
  • Exam answers
  • Grades or test results
  • Photos, videos, or other media
  • Browsing history

3. Locally Stored Data

The following data is stored ONLY on your device and is NOT sent to our servers:

  • Premium status (whether you have purchased the upgrade)
  • Number of tokens created today (for free account limitations)

This data can be deleted by clearing the app data through your device settings.

4. Exam Tokens

  • Exam tokens are temporary codes that link to exam URLs
  • Tokens have an expiration time (default: 2 hours)
  • Tokens do not contain personal information
  • Tokens are temporarily stored on our server and deleted after expiration

5. Internet Connection

The app requires an internet connection to:

  • Create exam tokens (Teacher Mode)
  • Validate tokens (Student Mode)
  • Load web exam pages (Google Forms, Kahoot, etc.)
  • Process purchases through Google Play

6. In-App Purchases

Purchases are processed entirely through the Google Play Billing system. We do NOT store your credit card or payment information. Please refer to Google's Privacy Policy for more information.

7. App Permissions

INTERNET Required to access web-based exam pages
Screen Pinning/LockTask To lock the screen during exams

8. Security Measures

  • FLAG_SECURE is active during exams to prevent screenshots and screen recording
  • WebView data (cache, cookies) is automatically cleared after exam completion
  • Domains are restricted to valid exam URLs only

9. Children's Privacy

This app is designed to be safe for use by children (students) because:

  • It does not collect personal data
  • It does not display advertisements
  • It has no social features or chat
  • It has no user-generated content

10. Changes to This Privacy Policy

We may update this privacy policy from time to time. Significant changes will be announced through app updates.
